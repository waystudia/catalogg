## Решение для WayYaam

1. Не переносить тип бизнеса, ресторанные настройки, зал, столы, кабинки и блюда.
2. Взять у «Мангала» только визуальный ритм: спокойная сетка, крупные понятные действия, компактные панели и единые отступы.
3. Разделить публичную витрину и рабочий справочник. «Витрина» остаётся просмотром клиента, «Товары» становится таблицей учёта.
4. Сделать сканирование единым механизмом для карточки товара, приёмки, склада и кассы.
5. Сохранять продуктовые роли и процессы: владелец, администратор, сборщик, команда, назначение заказа и чат по заменам.
6. На телефоне показывать строки как компактные карточки; на планшете — таблицу с закреплёнными действиями; на компьютере — полноценную таблицу и двухпанельную кассу.
