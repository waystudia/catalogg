# География ресторана и адрес самовывоза

Макет: [restaurant-geography-checkout-mockup.png](./restaurant-geography-checkout-mockup.png)

## Цель

Суперадмин и ресторан выбирают географию из единого справочника, а клиент в оформлении заказа сразу видит актуальную точку ресторана и открывает её на карте.

## Интерфейс настроек

- «Основной город» — зависимый select из `delivery_settlements.city_name`.
- После выбора города показывается информационная карточка «Точка ресторана: <город>».
- «Сёла и районы обслуживания» — прокручиваемый список checkbox, отфильтрованный по выбранному городу.
- При смене города населённые пункты прошлого города снимаются автоматически.
- На мобильном экране поля располагаются в одну колонку, список имеет собственный ограниченный скролл, вся форма остаётся вертикально прокручиваемой.
- Сохранение клиента синхронизирует `clients.primary_city`, `clients.service_settlements` и соответствующие поля `restaurant_delivery_settings` через существующие Edge Functions.

## Интерфейс checkout

- В режиме «На вынос» карточка показывает основной город и актуальный адрес ресторана.
- «Показать на карте» использует сохранённые координаты; если их нет — явную ссылку; если нет и её — поиск по сочетанию города и адреса.
- Выбор результата поиска в настройках точки заменяет прежний адрес, а не сохраняет устаревшее значение.
- Изменения таблиц `catalogs`, `restaurants` и `restaurant_delivery_settings` обновляют уже открытый публичный каталог через realtime-подписку.

## Критерии приёмки

1. Для «Курчалой» нельзя выбрать населённый пункт, привязанный только к «Грозный».
2. Смена «Грозный» → «Курчалой» удаляет несовместимые выбранные пункты до сохранения.
3. После сохранения в checkout появляется «Курчалой» без перезагрузки уже открытой страницы при работающем Supabase Realtime.
4. Адрес в карточке совпадает с последним сохранённым адресом профиля ресторана.
5. Кнопка карты открывает текущую точку и не зависит от старого вручную введённого URL при наличии координат.
6. На ширине 320–430 px ни одно поле не выходит за экран; форма и список населённых пунктов прокручиваются.
7. Логика GPS клиента, точность 10 м и ручная установка точки доставки не изменяются.

## Проверки

- Unit-контракты фильтрации городов/сёл и формирования ссылки на карту.
- `npm run lint`
- `npm run typecheck`
- `npm run build`
- Ручная мобильная проверка создания/редактирования клиента и режима «На вынос».
