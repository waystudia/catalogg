# Юридический комплект WayYaam

Комплект подготовлен по результатам аудита от 31 июля 2026 года. Он содержит 19 документов в каталогах `markdown`, `html`, `docx` и `pdf`; публичные HTML-копии находятся в `public/legal`.

## Перед публикацией

1. Устранить критические блокеры из `audit/2026-07-31-personal-data-audit.md`.
2. Заменить все `[ЗАПОЛНИТЬ]` и уточнить полный адрес, телефон, ИНН/статус оператора, ответственного, российский ЦОД, сроки и тарифы.
3. Проверить оферты, правовую модель ролей и уведомления у российского юриста.
4. Повторно запустить `scripts/generate_legal_pack.py`; обновить SHA-256 трёх публичных HTML в `src/shared/api/clientAccountApi.ts`.
5. Подать уведомления только после сверки с фактической production-архитектурой.
