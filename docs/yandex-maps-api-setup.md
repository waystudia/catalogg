# WayYaam: подключение Yandex Maps API и Yandex Navigator

В интерфейсе WayYaam встроенная карта не используется. Водитель открывает один подписанный маршрут `бизнес → клиент` в приложении Яндекс Навигатор, а затем возвращается в него через `yandexnavi://` без повторного создания ссылки.

## Два отдельных подключения

1. **Yandex Maps Tiles API** — отдельный браузерный API-ключ. Подготовлен модуль `src/shared/yandexMapsApi.ts`. Он не подключён к экрану и не расходует запросы, пока встроенная карта отключена.
2. **Yandex Navigator** — `client` и RSA-подпись ссылки. Подпись создаётся только в Supabase Edge Function; приватный ключ никогда не попадает в PWA.

Целевые бесплатные ограничения проекта:

- Tiles API: до 30 запросов тайлов в секунду;
- Navigator: до 5 000 подписанных переходов в сутки согласно согласованному сценарию подключения.

## 1. Создать ключ Tiles API

В кабинете разработчика Яндекса создать ключ для **Static API / Tiles API**, разрешить только production-домены WayYaam и сохранить публичный ключ в окружении сборки:

```dotenv
VITE_YANDEX_TILES_API_KEY=...
```

Ключ допустимо использовать в браузере, но для него обязательно настроить ограничения по доменам. Текущий продуктовый интерфейс этот ключ не вызывает.

## 2. Получить доступ к Navigator

В заявке Яндексу указать:

- приложение WayYaam для водителей;
- сценарий: маршрут из текущей точки водителя через точку бизнеса до клиента;
- URI-схему `yandexnavi://`;
- целевой лимит 5 000 переходов в сутки;
- production-домен и Android APK/ссылку на приложение, если их запросит Яндекс;
- юридическое лицо и контакт технического владельца.

После одобрения Яндекс выдаёт значение `client` и регистрирует публичный RSA-ключ.

## 3. Создать RSA-ключи

```bash
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out yandex-navigator-private.pem
openssl pkey -in yandex-navigator-private.pem -pubout -out yandex-navigator-public.pem
```

Передать Яндексу только `yandex-navigator-public.pem`. Приватный файл не добавлять в Git и не сохранять в переменных `VITE_*`.

## 4. Настроить Supabase secrets

Создать локальный файл вне Git, например `supabase/.env.navigator.local`:

```dotenv
YANDEX_NAVIGATOR_CLIENT_ID=полученный_client
YANDEX_NAVIGATOR_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----"
YANDEX_NAVIGATOR_DAILY_TRANSITION_LIMIT=5000
```

Затем загрузить секреты и развернуть функцию:

```bash
npx supabase secrets set --env-file supabase/.env.navigator.local
npx supabase functions deploy sign-yandex-navigator-route
```

Миграция `20260913180312_add_delivery_handoff_confirmation.sql` должна быть применена раньше функции. Она создаёт закрытый кеш подписанных маршрутов, журнал лимита и атомарную защиту от превышения 5 000 новых переходов за сутки.

## 5. Поведение и контроль лимита

- первый тап водителя вызывает Edge Function и создаёт подписанную ссылку;
- ссылка кешируется по доставке на сервере;
- после первого запуска кнопка становится «Вернуться в Навигатор» и использует голую URI-схему без новой подписи;
- смена GPS водителя не пересоздаёт ссылку;
- новая ссылка разрешена только через аварийную кнопку восстановления маршрута;
- при исчерпании дневного лимита сервер возвращает HTTP 429 и не подписывает новый переход;
- таблицы с подписанными URL и статистикой закрыты для `anon` и `authenticated`.

## 6. Проверка после получения ключей

Проверять на физическом iPhone/Android с установленным Яндекс Навигатором:

1. принять тестовый заказ с точными координатами бизнеса и клиента;
2. нажать «Открыть маршрут в Навигаторе» и убедиться, что порядок точек правильный;
3. вернуться в WayYaam — кнопка должна стать «Вернуться в Навигатор»;
4. нажать её несколько раз и проверить, что `signed_route_build_count` не увеличивается;
5. проверить отдельный аварийный rebuild и рост счётчика ровно на один;
6. завершить сценарий «Отдал заказ» → «Получил заказ» → свайп вправо.

Официальная документация: [подпись URI Яндекс Навигатора](https://yandex.ru/dev/navigator/doc/ru/concepts/navigator-commercial-use-signature), [параметры маршрута](https://yandex.ru/dev/navigator/doc/ru/concepts/navigator-url-params), [Tiles API](https://yandex.ru/maps-api/docs/tiles-api/index.html), [ограничения ключа](https://yandex.ru/maps-api/docs/tiles-api/limit.html).
