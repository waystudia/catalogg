# Дизайн клиентских заказов WayYaam

Откройте [общий storyboard](orders-experience-storyboard.html): три интерактивных экрана, варианты A/B/C и состояния заказа. Это автономный прототип с вымышленными данными, без API и реальных заказов.

Запуск из корня репозитория:

```sh
python3 -m http.server 4186 --bind 127.0.0.1 --directory docs/design-mocks/orders-experience
```

Адрес: http://127.0.0.1:4186/orders-experience-storyboard.html

- Главная: активный заказ под баннером, переход к деталям и пустое состояние.
- Мои заказы: веер, горизонтальные карточки, вертикальная лента; раскрытие, переход в детали и пустая история.
- Экран заказа: подтверждение с анимацией, приготовление, готовность, доставка, задержка и отмена. Учитывается reduced motion.
- Меню над макетами предназначены для просмотра состояний. Звонки и остальные разделы приложения не подключены.

Варианты дизайна ещё предстоит выбрать перед переносом в приложение. Публикация на production не входит в эту работу.
