# Макеты заказов на основе текущего WayYaam

[Открыть общий просмотр](orders-experience-storyboard.html).

Запуск: `npm run dev -- --host 127.0.0.1 --port 4175` из корня проекта.
Адрес: http://127.0.0.1:4175/docs/design-mocks/orders-experience/orders-experience-storyboard.html

React-прототип импортирует существующие `src/app/styles.css` и `src/pages/client-platform/client-platform.css`. Шапка, поиск, баннер, товары, нижняя навигация и базовые карточки используют разметку и классы текущего приложения; иконки — lucide-react, изображения — из проекта. Дополнительный CSS относится к новым блокам заказов и полосе управления макетом.

Сценарии: блок заказа под баннерами, «Мои заказы» (отдельные компактные карточки с переходом к деталям), оформление → подтверждение → главная. В деталях доступны ожидание, приготовление, готовность, доставка, задержка и отмена. Поддерживается reduced motion.

Это дизайн-прототип с демонстрационными данными. API заказов, звонки и реальные операции не подключены. Публикация на production не выполняется.
