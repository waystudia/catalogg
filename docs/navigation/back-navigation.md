# Правило возврата WayYaam

Кнопка «Назад» возвращает к предыдущему моменту пользователя: А → Б → В → Назад → Б → Назад → А. Нельзя подменять возврат переходом на привычную родительскую страницу.

Клиентские маршруты используют `ExactBackProvider` внутри HashRouter и `useExactBack(fallback)`. Общий PageHeader, статус заказа, отзывы, каталог и checkout применяют этот контракт. Журнал хранит ключи настоящих записей history и прокрутку; URL и router state восстанавливаются самим роутером. Новое открытие начинается сверху; POP восстанавливает прежнюю позицию. Вкладки заказов находятся в query, поэтому возвращаются вместе с маршрутом. Состояние журнала ограничено 100 записями в sessionStorage; при недоступном хранилище работает память текущей вкладки.

Переходы REPLACE сохраняют родительскую запись, PUSH создаёт следующий шаг, POP выбирает существующую запись. Перезагрузка сохраняет связь, если ключ текущей записи найден в журнале этой вкладки. Длина browser history не считается доказательством внутреннего перехода. Неизвестный прямой вход использует безопасный fallback с replace. Вход, водительская и административная области сбрасывают клиентский журнал, их рабочие процессы и права не меняются.

Локальные состояния (карточка товара, панели настроек, шаги форм и встроенный сканер) сохраняют собственные обработчики. Их нельзя без проверки заменять переходом на предыдущий URL: URL может вообще не изменяться. Сворачивание корзины — отдельное действие, открывающее каталог; оно не является кнопкой «Назад».

Инвентаризация архитектур: клиентский PageHeader — маршруты профиля, адресов, оплаты, избранного, заказов, уведомлений, города, категорий и материалов; публичный TopBar — заказ/отзывы/каталог; checkout — маршрут с локальным снимком корзины; продукт/панели/мастера — локальное состояние; администратор/водитель — отдельные защищённые рабочие области. Новые маршрутные кнопки клиента должны использовать общий hook. Нельзя заявлять проверку всех локальных и защищённых экранов по тесту только клиентского маршрута.

Поведенческие проверки: `tests/browser/exact-back.test.tsx`, `client-orders-list.test.tsx`, `checkout-navigation.test.tsx`, `cart-sheet-mobile.test.tsx`, `pwa-home-navigation.test.tsx`. Проверять реальные клики, вложенность, query/state, прокрутку, браузерные Back/Forward, прямой вход и перезагрузку на ширине 319 px.
