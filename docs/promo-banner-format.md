# Формат баннеров WayYaam

Пользователь утвердил размер по конкурсному изображению: **1774 × 887 px**, пропорции **2:1**.

Эталон: `platform-banner-media/2026-08-10/2328c283-7185-4c58-a8fa-cae333e56b4e.png`.
Размер проверен по naturalWidth/naturalHeight исходного изображения 31.10.2026.

Все слайды карусели, включая текстовые акции, используют этот формат. Ширина равна доступной ширине страницы, высота равна половине ширины. Фиксированные ограничения высоты не должны менять пропорции на телефонах и компьютерах. Например, рамка шириной 765 px имеет высоту 382,5 px; шириной 1072 px — 536 px.

Для новых изображений рекомендуется 1774 × 887 px или другой размер 2:1. Изображения и видео помещаются целиком; элементы управления остаются внутри рамки. Позиции текста/кнопок, переходы, индикаторы и автоматическое перелистывание сохраняются.
